# Marketplace Beauté

Projet de stage : marketplace C2C de produits de beauté (gloss, crayons, blush...)
avec paiement Stripe, interface acheteur et interface vendeur.

- `backend/` — Django + DRF + JWT + Stripe
- `frontend/` — Next.js + Tailwind

Voir le README de chaque dossier pour l'installation, et `ROADMAP.md` à la racine
pour la répartition du travail et le planning.
